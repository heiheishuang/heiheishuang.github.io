Publications

M^2Depth: Self-supervised Two-Frame Multi-camera Metric Depth Estimation
Yingshuang Zou, Yikang Ding, Xi Qiu, Haoqian Wang, Haotian Zhang
Arxiv, 2024.
Project Page / arXiv / code

We propose to construct spatial-temporal 3D cost volumes and design a spatial-temporal fusion (STF) module for surrounding depth estimation; we introduce the strong SAM prior into the depth estimation task and propose a multi-grained feature fusion (MFF) module to integrate SAM features with internal features for enhancing the depth quality in detail.

3D Face Arbitrary Style Transfer
Xiangwen Deng, Yingshuang Zou, Yuanhao Cai, Chendong Zhao, Yang Liu, Zhifang Liu, Yuxiao Liu, Jiawei Zhou, Haoqian Wang
Arxiv, 2023.
arXiv

We propose a novel framework FDST for 3D face arbitrary style transfer. We design an optimization-based face texture transfer module DDSG, which can jointly preserve the face shape and transfer the texture details even using large style weights. Experiments show that FDST can also accomplish tasks such as high-fidelity face texture reconstruction, region-controllable style transfer, large-pose face reconstruction, and artistic face reconstruction.
