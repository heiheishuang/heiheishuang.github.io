ICRA AI Robomaster Challenge

As a team leader, I led our team (Firefly) to participate in the ICRA Robomaster AI Challenge. In August of 2020, we got sixth place in the navigation and strategy groups, eighth place in the perception group in 72 terms.

My main work is as follows:

1. I built a simulation platform based on Gazebo, which can simulate sensor data and motion of robots. More importantly, this platform can cooperate with openai_ros package, which can provide the same standard reinforcement learning interface as openai gym. During COVID-19, the development of strategy and navigation mainly relies on this simulator.

[Link of simulation platform]

2. I led the development of the navigation part. We use cartographer-slam to build a map of the competition field and calculate the actual position of the current robot. Then, in the planning module, we modify the global-planning algorithm by inputting the path of another robot into the costmap of the current robot, so that we realize simple multi robot planning.

[Link of nwpu-v5-team]

3. I also participated in the coding of strategy part. We used the behavior tree method for action selection, so that robots on the field can complete different behaviors according to different information of the field.

Now we are working hard for 2021 competition!

A Wheeled Robot with Lidar

In my first summer vacation, I led our team won second place in the FIRA Roboworld Cup, Robosot Race Competition Development Group. This project is based on a ground detection robot.

In this project, the whole robot was designed by us. We put the sensor(depth camera and lidar), onboard computer and control board together like a burger. At the same time, considering the convenience of motion, we use the omni-directional wheel.

We use Intel NUC as an onboard computer so that it has enough calculation ability. We got the scan data from Rplidar A2, image data from Intel Realsense d435 and IMU data from Sanchi IMU. Our software system is based on the ROS framework and this robot can detect balls, estimate the distance, avoid obstacles, pick up the ball, location, planning and then put it in the right area autonomously. Our strategy system is based on a DFA (Deterministic Finite Automaton).

Except for the work of vision and hardware, I did all the rest of this system.

Image Super-resolution

This project is a coursework on Digital Media Technology. In this project, I use Pytorch to build two kinds of network structure, and train in the dataset. In the end, I got clearer images.

SRCNN is composed of three convolutional layers which conceptually consists of three operations:

  1. Patch extraction and representation;
  2. Non-linear mapping;
  3. Reconstruction.

SRCNN use mean square error as loss function and after 400 epoches of training, the result of SRCNN is better than image after bicubic interpolation, but still has an unnatural feeling.

SRResnet is composed of residual blocks, pixelshuffle layers and the others layers.

In general, the performance will improve if we enlarge the network scale, so I choose to add more layers or filters. Then I choose SRResnet( It is a generator of SRGAN) as second network structure. According to the paper, I coded the SRResnet and found a new dataset.

The loss function is still MSE. After 2000 epochs, although the improvement of PSNR is not very much, the result of SRResnet is more realistic.

MIDL-Compiler

This project is a coursework of Principles of compilation. In this project, I use C++ to complete the front end of the MIDL-Compiler.

In morphology analysis, I transform regular expressions into a finite automatic state machine, and use finite automatic state to analyze words.

In syntax analysis, I use Recursive Descent to complete the syntax analysis of the token lists.

In the end MIDL-Compiler can transform code into abstract syntax analysis tree and reminder errors from code.
